# Моя мережа (NetGuard)

Додаток для перевірки **власної** домашньої Wi-Fi мережі на Android (Samsung Galaxy A25, Android 8.0+).
Ніяких атак, перехоплення паролів чи роботи з чужими мережами — лише діагностика.

## Вкладки

- **Мережа** — SSID, рівень сигналу, швидкість з'єднання, канал/діапазон, IP телефону, IP роутера і DNS.
- **Пристрої** — швидке сканування вашої локальної підмережі (192.168.x.x, 1–254), щоб побачити,
  скільки пристроїв підключено зараз, і помітити незнайомі.
- **Ефір** — список сусідніх Wi-Fi мереж із каналами й рівнем сигналу, попередження, якщо ваш канал
  збігається з сусіднім (допомагає обрати вільніший канал у налаштуваннях роутера).
- **Поради** — чек-лист базової безпеки роутера (WPA2/WPA3, вимкнути WPS, змінити пароль адмінки тощо).

## Дозволи

- `ACCESS_FINE_LOCATION` / `NEARBY_WIFI_DEVICES` — вимога Android для читання SSID і списку сканованих мереж.
  Жодні координати нікуди не надсилаються, дозвіл використовується лише для Wi-Fi API.
- `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE`, `ACCESS_NETWORK_STATE`, `INTERNET` — для отримання інформації
  про з'єднання і пошуку пристроїв у вашій локальній мережі.

## Збірка

**Android Studio:** `File → Open` → обрати цю папку → `Run ▶`.

**GitHub Actions:** після пуша в `main` APK збирається автоматично —
вкладка *Actions* → останній запуск → *Artifacts* → `NetGuard-debug-apk`.
